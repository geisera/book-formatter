# Font records

Libre Baskerville is supplied by pinned `@fontsource/libre-baskerville`.
The unmodified Latin WOFF2 regular (400), italic (400), and bold (700) faces are
bundled locally. No Google Fonts or other remote font service is contacted.

Georgia is an optional system font; no Georgia font binary is distributed.
Its availability and fallback appearance depend on the user's operating system.
